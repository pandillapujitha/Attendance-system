**Student Attendance System**

A web-based application to manage student records, mark attendance, and generate attendance reports.

**✨ Features**
Student management
Mark student attendance
View attendance reports
Admin login and authentication
**🛠️ Technologies Used**
React
Vite
Node.js
Express.js
JavaScript
JSON file storage

**🚀 Getting Started**
Clone the repository:
git clone https://github.com/pandillapujitha/Attendance-system.git

Open the project folder and install the frontend and backend dependencies.
Start the backend server and frontend development server.
Open the local URL displayed by Vite in your browser.
**👩‍💻 Project Purpose**
This project simplifies student attendance management by providing a convenient way to maintain student records, record daily attendance, and review attendance reports.
